PFX to CRT and KEY Export Reference

Purpose
- Provide a short operator reference for extracting certificate and key material from a PKCS#12 (.pfx/.p12) file when a downstream system requires separate files.
- Prefer scripts/Certificates/Convert-PfxToPem.ps1 when the repository script satisfies the requirement.

Prerequisites
- OpenSSL is installed and available in the current shell.
- You have the import password for the source PFX file.
- The destination system is approved to receive exported private-key material.

Example workflow
1. Change to the folder containing the PFX file.
2. Export the encrypted private key:

   openssl pkcs12 -in .\input-certificate.pfx -nocerts -out .\server-encrypted.key

3. Export the end-entity certificate:

   openssl pkcs12 -in .\input-certificate.pfx -clcerts -nokeys -out .\server.crt

4. If the target system requires an unencrypted private key, create it explicitly:

   openssl rsa -in .\server-encrypted.key -out .\server.key

5. If a PEM output is required, convert the key or certificate as needed:

   openssl rsa -in .\server-encrypted.key -outform PEM -out .\server-encrypted.pem

Security notes
- Do not leave decrypted private keys in shared or temporary folders.
- Delete temporary exports after the target system is validated.
- Record where the exported material was transferred and who approved the transfer.
- Keep any passwords or passphrases out of shell history, screenshots, and tickets.

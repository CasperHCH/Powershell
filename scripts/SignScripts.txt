SignScripts Reference

Purpose
- This file is a short operator note for scripts/SignScripts.ps1.
- The PowerShell script is the source of truth. Do not duplicate logic here.

What the script does
- Selects or validates a code-signing certificate.
- Signs one or more PowerShell files.
- Supports validation-only and reporting-oriented workflows.
- Writes logs and optional output artifacts beside the script unless overridden.

Common examples
- Sign one script:

  .\SignScripts.ps1 -ScriptPath .\Example.ps1

- Preview a batch signing operation:

  .\SignScripts.ps1 -BatchMode -ScriptPath .\*.ps1 -ValidateOnly

- Generate a report while signing:

  .\SignScripts.ps1 -BatchMode -ScriptPath .\*.ps1 -GenerateReport

Operator checklist
- Confirm the code-signing certificate is trusted and not expired.
- Review the script list before using wildcard paths.
- Use validation mode before signing broad file sets.
- Store any generated reports with the change record when signing production automation.
